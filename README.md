# SIP (Sistem Informasi Presensi)

Aplikasi mobile untuk sistem presensi siswa dan guru berbasis Flutter.

## 📄 Privacy Policy

**[🔗 Akses Privacy Policy](https://frianprianas.github.io/SIP/)**

Privacy Policy aplikasi SIP dapat diakses melalui link di atas atau dalam folder `docs/`.

## 🚀 Fitur Utama

- ✅ Presensi real-time untuk siswa dan guru
- 📊 Dashboard monitoring kehadiran
- 🔔 Notifikasi push Firebase
- 📝 Sistem catatan dan laporan
- 📅 Manajemen jadwal
- 🎯 Role-based access (Siswa/Guru/Admin)

## 🛡️ Keamanan & Privacy

- 🔐 Enkripsi data sensitif
- 🔒 Autentikasi berlapis
- 📱 Firebase security
- 📋 Compliance dengan UU PDP Indonesia

## 📱 Platform Support

- Android
- iOS
- Web (Dashboard admin)
