Kebijakan Privasi
Aplikasi SIP (Sistem Informasi Presensi)

Terakhir diperbarui: 1 Oktober 2025

1. Pendahuluan

Aplikasi SIP (Sistem Informasi Presensi) berkomitmen untuk melindungi privasi dan keamanan data pengguna. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan aplikasi mobile SIP.

2. Informasi yang Kami Kumpulkan

2.1 Data Identitas

  • Siswa: NIS (Nomor Induk Siswa), nama lengkap, kelas
  • Guru/Tenaga Kependidikan: NIPY (Nomor Induk Pegawai Yayasan), nama lengkap, jabatan, keterangan

2.2 Data Kredensial Login

  • Email atau username
  • Password (disimpan dalam bentuk terenkripsi)

2.3 Data Presensi dan Kehadiran

  • Waktu tap/scan presensi
  • Status kehadiran (masuk, hadir, tidak hadir, izin, sakit)
  • Lokasi presensi (jika menggunakan sistem berbasis RFID/IoT)
  • Riwayat kehadiran harian, bulanan, dan tahunan

2.4 Data Jadwal dan Akademik

  • Jadwal pelajaran
  • Data kelas yang diampu (untuk guru)
  • Informasi mata pelajaran

2.5 Data Catatan

  • Catatan siswa (dibuat oleh guru)
  • Catatan guru (untuk keperluan internal)
  • Rekap dan laporan presensi

2.6 Data Teknis

  • Firebase Cloud Messaging (FCM) tokens untuk notifikasi push
  • Informasi perangkat (tipe perangkat, versi OS)
  • Log aktivitas aplikasi untuk troubleshooting

3. Cara Kami Menggunakan Data

3.1 Tujuan Utama

  • Mencatat dan memantau kehadiran siswa dan guru
  • Menyediakan dashboard informasi presensi real-time
  • Mengirim notifikasi terkait kehadiran
  • Membuat laporan dan rekap presensi
  • Memfasilitasi komunikasi antara guru dan siswa melalui sistem catatan

3.2 Tujuan Administratif

  • Manajemen pengguna dan kontrol akses
  • Pemeliharaan dan peningkatan sistem
  • Analisis penggunaan untuk optimalisasi aplikasi
  • Backup dan recovery data

4. Berbagi Data dengan Pihak Ketiga

4.1 Tidak Ada Penjualan Data

Kami tidak menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak ketiga untuk tujuan komersial.

4.2 Pihak Ketiga yang Dapat Mengakses Data

  • Firebase (Google): Untuk layanan cloud messaging dan analytics
  • Hosting Provider: Untuk penyimpanan database dan server aplikasi
  • Pihak Berwenang: Jika diwajibkan oleh hukum atau regulasi pemerintah

4.3 Perlindungan dalam Berbagi

Semua pihak ketiga yang mengakses data wajib mematuhi standar keamanan dan privasi yang setara dengan kebijakan ini.

5. Keamanan Data

5.1 Enkripsi

  • Password pengguna disimpan dengan enkripsi hash
  • Transmisi data menggunakan protokol HTTPS/SSL
  • Data sensitif dienkripsi sebelum disimpan

5.2 Kontrol Akses

  • Sistem autentikasi berlapis dengan session management
  • Role-based access control (siswa, guru, admin)
  • Audit trail untuk aktivitas login dan akses data

5.3 Infrastruktur

  • Server dilindungi dengan firewall dan sistem monitoring
  • Backup data reguler dengan enkripsi
  • Update keamanan sistem secara berkala

6. Retensi Data

6.1 Data Aktif

Data pengguna aktif disimpan selama masa studi/kerja di institusi pendidikan terkait.

6.2 Data Historis

  • Data presensi disimpan untuk keperluan laporan dan arsip institusi
  • Data dapat disimpan hingga 7 tahun setelah pengguna tidak aktif
  • Data non-esensial akan dihapus setelah periode retensi berakhir

6.3 Penghapusan Data

Pengguna dapat meminta penghapusan data pribadi dengan menghubungi administrator sistem, sesuai dengan ketentuan yang berlaku.

7. Hak Pengguna

7.1 Hak Akses

  • Melihat data pribadi yang tersimpan dalam sistem
  • Meminta salinan data pribadi dalam format yang dapat dibaca

7.2 Hak Koreksi

  • Memperbaiki data pribadi yang tidak akurat
  • Memperbarui informasi kontak dan profil

7.3 Hak Penghapusan

  • Meminta penghapusan akun dan data pribadi
  • Penarikan persetujuan penggunaan data (dengan keterbatasan tertentu)

7.4 Hak Portabilitas

  • Meminta transfer data dalam format terstruktur
  • Ekspor riwayat presensi dan data pribadi

8. Cookies dan Teknologi Pelacakan

8.1 Local Storage

Aplikasi menggunakan SharedPreferences (Android/iOS) untuk menyimpan:

  • Token autentikasi
  • Preferensi pengguna
  • Cache data untuk performa aplikasi

8.2 Analytics

Kami dapat mengumpulkan data analytics anonim untuk:

  • Memahami pola penggunaan aplikasi
  • Mengidentifikasi dan memperbaiki bug
  • Meningkatkan user experience

9. Notifikasi Push

9.1 Firebase Cloud Messaging

  • Kami menggunakan FCM untuk mengirim notifikasi kehadiran
  • Token FCM disimpan untuk pengiriman notifikasi yang tepat sasaran
  • Pengguna dapat menonaktifkan notifikasi melalui pengaturan perangkat

9.2 Jenis Notifikasi

  • Pemberitahuan kehadiran real-time
  • Pengingat jadwal dan kegiatan
  • Informasi sistem dan maintenance

10. Perlindungan Data Anak

10.1 Kebijakan Khusus

Mengingat aplikasi ini digunakan oleh siswa yang mungkin berusia di bawah 18 tahun:

  • Kami menerapkan perlindungan ekstra untuk data siswa
  • Akses data siswa dibatasi hanya untuk guru dan staff yang berwenang
  • Orang tua/wali dapat meminta informasi tentang data anak mereka

10.2 Persetujuan

Penggunaan aplikasi oleh siswa di bawah umur dianggap telah mendapat persetujuan dari institusi pendidikan dan orang tua/wali.

11. Pembaruan Kebijakan

11.1 Notifikasi Perubahan

  • Setiap perubahan kebijakan akan dinotifikasikan melalui aplikasi
  • Versi terbaru selalu tersedia dalam aplikasi
  • Perubahan signifikan akan memerlukan persetujuan ulang pengguna

11.2 Riwayat Versi

Tanggal pembaruan dan perubahan utama akan dicatat dalam riwayat versi kebijakan.

13. Dasar Hukum

Kebijakan ini disusun berdasarkan:

  • Undang-Undang No. 27 Tahun 2022 tentang Perlindungan Data Pribadi
  • Peraturan Pemerintah terkait Sistem Elektronik
  • Standar internasional ISO 27001 untuk keamanan informasi
  • Regulasi institusi pendidikan yang berlaku

14. Yurisdiksi

Kebijakan ini tunduk pada hukum Republik Indonesia. Setiap sengketa akan diselesaikan melalui pengadilan yang berwenang di Indonesia.
